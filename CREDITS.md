# Credits

Third-party work in this site, and the terms it comes under. This file is the
full list. On screen, the Workbench (`/workbench`) prints only the map credit
OpenStreetMap asks for, from [`content/credits.md`](content/credits.md).

## Map data

The Atlanta skyline behind the Workbench's window is rendered from
OpenStreetMap building footprints and heights.

Map data © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright),
available under the [Open Database License (ODbL)](https://opendatacommons.org/licenses/odbl/).
